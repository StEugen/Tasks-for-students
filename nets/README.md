# Networking laboratories

These laboratories continue after basic networking theory and use isolated VirtualBox machines.
They are designed for a future security specialist who needs to understand both attacker visibility
and defender controls.

## Laboratories

1. [VirtualBox network: observe, enumerate, and defend](virtualbox-network-lab/README.md)

## Reporting requirement

Submit each laboratory as a security assessment report using the shared
[security laboratory report template](../templates/security-lab-report-template.md). Commands and
screenshots belong in evidence or appendices; the main report must explain scope, observations,
findings, impact, recommendations, and retest results.

## Safety rules

- Use only machines and networks owned by you or explicitly assigned by the teacher.
- Keep the laboratory network on **Internal Network** or **Host-only Adapter**.
- Do not attach intentionally vulnerable services to Bridged Networking.
- Take VM snapshots before changing network or firewall configuration.
- Record commands, observations, and conclusions. A screenshot without an explanation is decoration, not evidence.
